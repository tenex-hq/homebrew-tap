# tenex-hq/homebrew-tap

Homebrew tap for [tenex-hq](https://github.com/tenex-hq) tools.

## Install

```bash
brew install tenex-hq/tap/claude-runway
```

## Casks

| Cask | What it is |
|---|---|
| [`claude-runway`](https://github.com/tenex-hq/claude-runway) | How much of your Claude subscription allowance is left, and whether it will last to the reset |

Everything under `Casks/` is generated by GoReleaser when the source repository cuts a
release. Do not edit those files by hand; the next release overwrites them.

The binaries they point at are not code-signed, so the casks clear the macOS quarantine flag
on install. See the source repository's README for what that trades away, and for
build-from-source alternatives that avoid the question entirely.
